# تحديث صفحة الدليفري — الحضور والتنبيهات والسياسات والرسم البياني

## المنفذ
- إضافة إغلاق النوافذ بزر ESC.
- تحويل أيقونة الجرس إلى نافذة تنبيهات فعلية بدل الانتقال لصفحة أخرى.
- عرض تنبيهات الإدارة إن وجدت من جدول `rider_notifications` مع تنبيهات تلقائية للفواتير المكررة وأوردرات ×1.5 والأوردرات الفاشلة والإجراءات تحت المراجعة.
- إضافة قسم واضح للسياسات والتعليمات داخل صفحة الدليفري.
- إضافة نافذة تفصيلية للسياسات والتعليمات.
- إصلاح قراءة حالة الحضور بعد التسجيل: الصفحة تبحث الآن عن سجل اليوم أو أي سجل حضور مفتوح بدون انصراف حتى لا تظل تعرض "لم يتم تسجيل الحضور بعد" بعد الحفظ.
- تحسين الرسم البياني لتطور الأداء اليومي خلال الدورة: شبكة خلفية، مساحة ملونة، نقاط واضحة، أرقام فوق النقاط، وملخص المتوسط/أعلى يوم/الإجمالي.

## ملاحظات تشغيل
- لا يوجد SQL إلزامي جديد لهذا التحديث.
- إذا كان جدول `rider_notifications` غير موجود، التطبيق يتجاهل الخطأ ويعرض التنبيهات التلقائية فقط.
- إذا أردت تنبيهات إدارية فعلية لاحقًا، أنشئ جدول `rider_notifications` أو استخدم الجدول الموجود من التحديثات السابقة.
