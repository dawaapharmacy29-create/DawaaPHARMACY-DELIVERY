# تشغيل التطبيق كتطبيق هاتف PWA

تم تجهيز التطبيق ليعمل كتطبيق هاتف قابل للتثبيت من المتصفح بعد نشره على Vercel.

## Android / Chrome
1. افتح رابط التطبيق من Chrome.
2. اضغط زر **تثبيت التطبيق على الهاتف** عند ظهوره، أو افتح قائمة Chrome واختر **Install app** / **Add to Home screen**.
3. سيظهر التطبيق على الشاشة الرئيسية باسم **Dawaa Delivery**.

## iPhone / Safari
1. افتح رابط التطبيق من Safari.
2. اضغط زر المشاركة.
3. اختر **Add to Home Screen / إضافة إلى الشاشة الرئيسية**.
4. اضغط **Add / إضافة**.

## ملاحظات مهمة
- يجب أن يكون التطبيق منشورًا على HTTPS، وهذا متوفر في Vercel.
- زر التثبيت يظهر تلقائيًا عندما يرى المتصفح أن التطبيق صالح للتثبيت.
- تم إضافة أيقونات PNG و Maskable Icons لتحسين التثبيت على Android و iPhone.
- تم إضافة نافذة داخل التطبيق ترشد المستخدم لتثبيت التطبيق.
