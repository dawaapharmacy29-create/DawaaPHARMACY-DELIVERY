# تطوير صفحة الدليفري — تصميم موبايل احترافي

## ما تم تنفيذه

تم إعادة بناء واجهة صفحة الدليفري `/rider` لتصبح أقرب لتطبيق موبايل فعلي، مع الحفاظ على اللغة العربية الرسمية بدل اللهجة العامية.

### 1. أعلى الصفحة
- هيدر جديد بتدرج لوني أخضر/تركوازي.
- إضافة لوجو صيدليات دواء داخل الهيدر.
- عرض اسم المندوب والفرع والتاريخ.
- تنبيه واضح بحالة الحضور.

### 2. أولوية الإجراءات
تم جعل أهم الإجراءات في أعلى الصفحة:
1. تسجيل أوردر.
2. تسجيل مشوار.
3. تسجيل حضور / انصراف.
4. تسجيل إذن.

### 3. ملخص اليوم
أضيفت بطاقات واضحة لكل من:
- أوردرات اليوم.
- مشاوير اليوم.
- أوردرات مضاعفة ×1.5.
- قيد المراجعة.
- فاشلة لا تُحتسب.

كل بطاقة قابلة للضغط وتفتح التفاصيل المرتبطة بها.

### 4. ملخص الدورة
يعرض:
- إجمالي أوردرات الدورة.
- إجمالي مشاوير الدورة.
- عدد المسلمة.
- عدد ×1.5.
- عدد الفاشلة.
- نسبة التقدم نحو الهدف.

### 5. تطور الأداء اليومي خلال الدورة
تم إضافة رسم بياني Line Chart يعرض تطور أداء المندوب خلال الدورة الحالية، اعتمادًا على الأوردرات والمشاوير المسجلة.

### 6. ملخص الخصومات والأذونات
تم إضافة بطاقة تعرض:
- عدد الخصومات المعتمدة.
- قيمة الخصومات.
- عدد الأذونات.
- آخر إذن مسجل.
- آخر سبب أو ملاحظة مسجلة.
- قيمة المكافآت إن وجدت.

### 7. التنبيهات المهمة
تعرض تنبيهات فعلية حسب البيانات:
- فواتير مكررة.
- طلبات ×1.5 قيد الموافقة.
- أوردرات فاشلة لا تُحتسب.
- إجراءات أو ملاحظات تحت المراجعة.

### 8. شريط تنقل سفلي للموبايل
تم إضافة Bottom Navigation مناسب للموبايل:
- الرئيسية.
- الأوردرات.
- المشاوير.
- التقارير.
- المزيد.

