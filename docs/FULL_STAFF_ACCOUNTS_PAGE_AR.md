# صفحة كل حسابات الفريق

الصفحة تعرض كل الحسابات وليس الدليفري فقط.

مزايا الصفحة:
- بحث بالاسم أو username أو الدور.
- فلترة حسب الفرع والدور والحالة.
- إضافة حساب مدير/موظف بدون ربطه بمندوب.
- إنشاء حساب للدليفري الذي لا يملك حساب.
- تعديل username والدور والفرع.
- إعادة تعيين PIN.
- تفعيل/إيقاف الحساب.
- تصدير CSV.

الأدوار المدعومة:
- rider
- branch_manager
- shift_manager
- operations_manager
- branches_manager
- general_manager
- admin

ملاحظة أمنية:
الـ PIN الحالي لا يظهر بعد تشفيره. يظهر PIN الجديد مرة واحدة فقط بعد الإنشاء أو إعادة التعيين.
