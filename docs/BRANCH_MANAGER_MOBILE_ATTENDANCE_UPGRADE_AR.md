# تحديث صفحة الدليفري ولوحة مدير الفرع

## ما تم تنفيذه

1. **تطوير صفحة الدليفري للهاتف**
   - تحسين النصوص إلى العربية الرسمية.
   - إظهار تحذير واضح إذا سجل المندوب حضورًا ولم يسجل انصرافًا.
   - تحسين رسائل الحضور والانصراف وحفظ الأوردر والمشوار.
   - الحفاظ على الواجهة كتطبيق PWA قابل للإضافة على شاشة الهاتف.

2. **إصلاح الحضور والانصراف**
   - إضافة دالة قاعدة بيانات `rider_record_attendance` لتسجيل الحضور والانصراف بأمان.
   - منع تكرار الحضور أو الانصراف لنفس اليوم.
   - تسجيل إجمالي الدقائق بين الحضور والانصراف.
   - استمرار وجود fallback داخل التطبيق في حال لم يتم تشغيل ملف SQL بعد.

3. **لوحة مدير الفرع**
   - إضافة صفحة جديدة: `/admin/branch`.
   - تعرض بيانات الفرع الحالي فقط عند وجود `branch_id` في حساب مدير الفرع.
   - تعرض مؤشرات الفرع: أوردرات الدورة، المسلمة، الفاشلة، ×1.5، المكررة، المشاوير، المشاوير المعلقة.
   - تمكن مدير الفرع من:
     - تحويل أوردر لمندوب آخر.
     - طلب تحويل أوردر إلى مشوار.
     - تسجيل طلب خصم.
     - تسجيل طلب مكافأة.
     - حذف حفظي للأوردر دون مسح نهائي.
   - كل إجراء يتطلب سببًا واضحًا ويتم حفظ اسم منفذ الإجراء.

4. **اللغة**
   - تم تقليل اللهجة العامية في صفحة الدليفري والرسائل الأساسية واستبدالها بعربية أوضح.

## ملف SQL المطلوب تشغيله

شغّل الملف التالي في Supabase SQL Editor:

`supabase/33_branch_manager_mobile_attendance_hardening.sql`

## الاختبار المطلوب بعد النشر

1. دخول مندوب.
2. تسجيل حضور.
3. تحديث الصفحة والتأكد أن الحضور ظاهر.
4. تسجيل انصراف والتأكد من حساب الدقائق.
5. دخول مدير فرع.
6. فتح `/admin/branch`.
7. تحويل أوردر لمندوب آخر مع سبب.
8. تسجيل طلب خصم أو مكافأة.
9. التأكد من ظهور الطلبات في مراجعة المدير العام.

## مقترحات المرحلة التالية

- إضافة صفحة سياسات فعلية مقسمة إلى: الأوردرات، المشاوير، الحضور، الخصومات، المكافآت.
- إضافة إشعارات Push للموبايل عند وجود أوردر ×1.5 أو فاتورة مكررة أو طلب خصم.
- إضافة تقرير مدير الفرع اليومي PDF.
- إضافة سجل تدقيق كامل لكل إجراء في واجهة منفصلة.
