# ربط دليفري بجهاز واحد + إصلاح الدخول والريفريش

## ما تم تنفيذه
- كل حساب دليفري يرتبط بأول جهاز يدخل منه.
- لو دخل من جهاز آخر يظهر خطأ: الحساب مربوط بجهاز آخر.
- المدير يمكنه فك ربط الجهاز أو اعتماد جهاز جديد من خلال RPC:
  - admin_reset_rider_device
  - admin_approve_rider_device
- المديرين ليس عليهم قفل جهاز واحد.
- إصلاح مشكلة تحويل username إلى uppercase.
- إصلاح مشكلة تخزين account_id كأنه rider_id.
- إصلاح refresh والروت:
  - الدليفري إلى /rider
  - مدير الفرع إلى /admin/branch
  - المدير العام/الأدمن إلى /admin
