# تحديث تحميل التطبيق على الموبايل + التنبيهات

## ما تم إضافته
1. دعم PWA:
   - manifest.webmanifest
   - service worker
   - زر/رسالة تحميل التطبيق على الموبايل
   - أيقونة على الشاشة الرئيسية

2. دعم التنبيهات:
   - جدول rider_notifications
   - تنبيه عام لكل الدليفري
   - تنبيه خاص للدليفري
   - تنبيه عند:
     - إضافة أو تعديل سياسة
     - تسجيل خصم
     - تسجيل مكافأة أو حافز
     - تغيير حالة أوردر
     - إلغاء/حذف أوردر
     - تغيير احتساب الأوردر
     - طلبات ×1.5
     - إذن أو إجازة

3. داخل صفحة الدليفري:
   - زر تفعيل إشعارات الهاتف
   - متابعة Realtime للتنبيهات الجديدة
   - عرض التنبيهات داخل التطبيق
   - إشعار Browser Notification إذا وافق المستخدم

## مهم
الإشعارات تعمل داخل التطبيق ومع فتحه/تثبيته. الإشعارات التي تصل والهاتف مغلق أو التطبيق مقفول بالكامل تحتاج مرحلة Web Push كاملة بمفاتيح VAPID أو Firebase، ويمكن تنفيذها لاحقًا.
